# 📖 Guide Utilisateur - VestyWinBox

## 🎯 Introduction

Bienvenue dans **VestyWinBox**, votre application de gestion système Windows moderne et intuitive ! Ce guide vous accompagnera dans l'utilisation de toutes les fonctionnalités de l'application.

## 🚀 Premiers Pas

### Installation
1. **Téléchargement** : Récupérez la dernière version depuis le repository GitHub
2. **Installation** : Exécutez le fichier `.exe` et suivez les instructions
3. **Premier lancement** : L'application se configure automatiquement

### Interface Principale
L'interface de VestyWinBox est organisée en plusieurs sections :
- **Sidebar** : Navigation entre les différentes pages
- **Header** : Informations système et actions rapides
- **Contenu principal** : Zone de travail spécifique à chaque page

## 🏠 Dashboard Principal

### Vue d'ensemble
Le Dashboard est votre centre de contrôle principal, affichant :
- **Heure actuelle** en temps réel
- **Tuiles d'action rapide** pour les tâches courantes
- **Statistiques système** en temps réel

### Tuiles d'Action Rapide

#### 🔄 Sauvegarder
**Fonction** : Sauvegarde automatique des dossiers utilisateur
**Utilisation** :
1. Cliquez sur la tuile "Sauvegarder"
2. Choisissez le dossier de destination
3. Sélectionnez les dossiers à sauvegarder :
   - Bureau
   - Images
   - Documents
   - Vidéos
   - Téléchargements
   - Musique
4. Cliquez sur "Démarrer la sauvegarde"
5. Suivez la progression en temps réel

#### 🛡️ Intégrité des fichiers système
**Fonction** : Vérification de l'intégrité des fichiers Windows
**Utilisation** :
1. Cliquez sur la tuile "Intégrité"
2. Cliquez sur "Démarrer la vérification"
3. Attendez la fin de l'analyse (peut prendre plusieurs minutes)
4. Consultez le rapport détaillé

#### 🧹 Nettoyer
**Fonction** : Nettoyage système complet
**Options disponibles** :
- [ ] Fichiers temporaires
- [ ] Corbeille
- [ ] Cache des navigateurs
- [ ] Fichiers Windows Update
- [ ] Logs système

**Utilisation** :
1. Cliquez sur la tuile "Nettoyer"
2. Sélectionnez les éléments à nettoyer
3. Cliquez sur "Démarrer le nettoyage"
4. Suivez la progression

#### 🔓 Désactiver l'UAC
**Fonction** : Désactivation du Contrôle de Compte Utilisateur
**⚠️ Attention** : Cette action réduit la sécurité du système
**Utilisation** :
1. Cliquez sur la tuile "UAC"
2. Lisez l'avertissement de sécurité
3. Confirmez votre choix
4. Redémarrez le système si demandé

#### 🔄 Options de Redémarrage
**Fonction** : Redémarrage avancé du système
**Options disponibles** :
- **Mode Sans Échec** : Redémarrage en mode diagnostic
- **BIOS** : Accès direct au BIOS
- **Démarrage Avancé** : Options de récupération Windows

**Utilisation** :
1. Cliquez sur la tuile "Redémarrage"
2. Choisissez l'option souhaitée
3. Confirmez l'action

### Actions Rapides Supplémentaires

#### ⭐ Sauvegarder Favoris
**Fonction** : Sauvegarde des favoris Chrome et Edge
**Utilisation** :
1. Cliquez sur la tuile "Sauvegarder Favoris"
2. Entrez le chemin de destination (ex: `D:\BackupFavoris`)
3. Confirmez l'action
4. Vérifiez le résultat

#### 🚫 Désactiver Télémétrie
**Fonction** : Désactivation de la collecte de données Windows
**Utilisation** :
1. Cliquez sur la tuile "Désactiver Télémétrie"
2. Confirmez l'action
3. Vérifiez que les services sont désactivés

#### 💾 Point de Restauration
**Fonction** : Création d'un point de restauration système
**Utilisation** :
1. Cliquez sur la tuile "Point de Restauration"
2. Entrez une description (ex: "Avant installation logiciel")
3. Cliquez sur "Créer"
4. Attendez la confirmation

#### ⚡ Activer GodMode
**Fonction** : Activation du mode GodMode Windows
**Utilisation** :
1. Cliquez sur la tuile "Activer GodMode"
2. Confirmez l'action
3. Un dossier "GodMode" apparaît sur le Bureau

#### 🔋 Rapport Batterie
**Fonction** : Génération d'un rapport de batterie détaillé
**Utilisation** :
1. Cliquez sur la tuile "Rapport Batterie"
2. Attendez la génération
3. Le rapport s'ouvre dans votre navigateur

#### 🔒 Vérifier Secure Boot
**Fonction** : Vérification du statut Secure Boot
**Utilisation** :
1. Cliquez sur la tuile "Vérifier Secure Boot"
2. Attendez l'analyse
3. Consultez le résultat détaillé

### Problèmes Courants

1. **Vérifiez** les droits administrateur

#### Erreurs de commandes système

2. **Exécutez** en tant qu'administrateur
3. **Consultez** les logs d'erreur

#### Performance lente
1. **Fermez** les autres applications
2. **Vérifiez** l'espace disque
3. **Redémarrez** le système
